# 安全边界：HTTP 免登录 LAN 面板

用户明确要求不使用 HTTPS、不需要面板密码登录。本版本删除管理员认证、Cookie 会话、密码初始化/重置与 TLS 监听，不提供隐蔽的重新启用选项。Steam 账号与 Steam Guard 属于 Valve 授权，不在删除范围内。

## 谁能做什么

允许的 LAN 来源可以打开面板、读取配置/日志/诊断，并控制该游戏实例。这不是多用户隔离系统。HTTP 不加密，包括网页提交的 Steam 密码、验证码与可能存在的游戏连接密码。不得映射到公网，不得在不可信共享 LAN 输入凭据。

Nginx LAN allow/deny 是入口限制；单 CT 的 PVE 防火墙规则仅在对应防火墙启用时生效。后端只绑定 127.0.0.1:8765，生产启动必须有 allowed_hosts。Host/Origin、JSON 内容类型与自动 CSRF 令牌继续阻止常见跨站操作；令牌不是认证，不限制同一 LAN 中已有访问权的设备。

## 保留的边界

游戏和 SteamCMD 以 steam 用户运行，网页以 dotapanel 运行；应用与系统服务代码 root-owned。Unix socket 仅 dota-control 组可访问。无 shell=True、任意命令/路径输入、sudo 代理、root 游戏进程、公共 RCON 或 Docker socket。

Steam 密码/Guard 不放入 argv、项目配置、持久任务记录和应用日志。仅在内存与 PTY 传入；不承诺 Python/浏览器内存物理擦除。Valve 自身登录缓存仍属敏感数据。维护互斥、在线更新明确停服授权、失败保留维护锁、有限自动重试均保留。

配置备份可能含游戏连接密码/Steam 账号名；PVE 全量备份包含 Steam 缓存。排错前审阅脱敏诊断，不发送整个 Steam home，不把凭据写进 Git。未知格式的上游秘密不保证全部自动识别。

## 升级检查

升级脚本只移除本项目固定旧面板 auth.json、初始凭据文件及 server.crt/server.key，不触碰其他 Nginx 站点或游戏缓存。重新部署后验证 HTTP 直接打开、无登录框、无 HTTPS 跳转/SSL 监听，检查跨站 POST 被拒绝以及白名单外访问被拒绝。

pexpect/forkpty 的多线程警告仍未解决；见测试报告。资源监控仅为只读观测，不授予额外宿主权限。


## 1.2.0 机器人扩展

固定 Valve 元数据接口，App570/Bot标签/单条目验证；SteamCMD 仅数字ID，受限目录查找。ZIP/VPK/目录路径与大小检查，拒绝链接/特殊文件/冲突路径，不执行安装器，不接受任意 URL 或 Shell。第三方 Lua 最终在游戏进程内执行，只安装信任作者；本项目不是 Lua 恶意代码沙箱。

下载缓存/不可变脚本库和对局部署目录分开。只在停服启动前复制，原目录备份与 journal 帮助恢复；不保证断电文件系统持久性，不替代离线备份。入口标记只辅助运行诊断，不是可信认证或完整 AI 正确性的证明。

HTTP 免密码入口不变，白名单 LAN 内所有人可下载/选用脚本。请勿公网暴露；Steam授权输入通过HTTP是明文。Bot下载/选择不会扩大 agent 的系统权限。
