# 使用帮助

这是管理你自己的 Dota 2 LAN 实例的面板，不是 Steam 客户端，也不是 Valve 官方匹配服务。默认只向指定 LAN 提供 HTTP 8443，且不校验面板管理员密码；游戏默认 UDP 27015。

## 1. 面板与 Steam 账号

面板无需账号或密码，打开后会自动建立管理会话。SteamCMD 页面使用的是 Steam 登录账号名，不是个人昵称或邮箱。面板不要求你公开或发送给开发者任何账号密码。

通过 `http://CT地址:8443` 访问。HTTP 不提供传输加密，只应在受信任 LAN 内使用，禁止公网端口转发；IP 建议静态或 DHCP 保留。

## 2. 首次开服

打开面板 → SteamCMD → 输入 Steam 登录名/密码 → 测试登录/授权 → 完成 Steam Guard 或手机批准 → 安装 Dota 2（含校验） → 等待任务成功 → 检查服务器配置 → 启动服务器 → 在另一台设备的 Dota 2 控制台 connect 到 CT 的 IP:游戏端口。

安装会从 Valve 下载 App 570 Linux 内容，ZIP 不含游戏。不要依赖匿名下载可用。初始环境安装不下载完整游戏，也不自动开服。客户端安装/更新、Steam 授权与 LAN 建服是不同步骤，不能据此保证完全断网可玩。

```text
connect 192.168.1.70:27015
```

这是示例 IP；使用概览页提供的连接命令。如果设置了游戏连接密码，按客户端提示输入或在客户端控制台先设置对应 password。先验证地图、选人和实际对局，再把它当作可用服务器。

## 3. 页面说明

| 页面 | 用途 |
|---|---|
| 运行概览 | 启动/停服/重启，连接命令，进程与本地资源状态 |
| SteamCMD | 授权、安装、更新、校验、一次性密码/Guard 补交、任务取消 |
| 任务记录 | 查看实际完成/失败/取消/中断；点击任务名看日志 |
| 日志与控制台 | 游戏/代理/历史任务日志；受限 status/bots/pause/say |
| 服务器配置 | 名称、端口、地图、模式、游戏密码与自动开服/有限崩溃重试 |
| 备份与诊断 | 配置快照、停服恢复、下载快照、脱敏诊断 |

“代理在线”仅表示管理链路可达；“进程运行中”不代表建图完毕；“发现 UDP 监听”不是客户端联机测试。面板没有伪造的玩家数或下载百分比。

## 4. Steam Guard 怎么提交

已经有验证码时可随登录提交。SteamCMD 运行中要求验证码/密码时，顶部出现一次性输入框，输入后点击安全提交。页面刷新不会结束等待任务；等待输入最多 5 分钟，超时后重新发起。手机批准需在你的 Steam 手机客户端确认，面板不会替你批准，也不绕过 Steam Guard。

应用不保存 Steam 密码/验证码，不放进进程命令行或应用日志。Valve 自己可能写登录缓存，后续更新有时可留空密码复用，有时需要重新验证。输入从页面清除不等于可证明的浏览器/系统内存擦除。

当日 SteamCMD 提示发生变化、网页不能识别时，按 DEPLOYMENT.md 的控制台首次授权流程处理；不要关闭 Steam Guard。先停服/结束任务，不能网页和控制台同时运行两个 SteamCMD。

## 5. 正常更新

比赛结束后停止服务器，等停止任务成功，再点击更新。或明确勾选“允许本次维护先停止正在运行的服务器”。“成功后恢复原先运行中的服务器”仅恢复任务开始时已在线的实例；原本没开服不会因此被自动开服。

一次只能运行一个变更任务。正在更新时不能启动游戏或再次更新。失败后检查任务日志；失败/取消保留维护保护标记，成功更新或校验后才解除。不要手工删除标记规避检查。

validate 校验/修复可能覆盖 Valve 管理文件的手动改动。你在面板保存的配置位于独立 JSON，正常更新不会改掉它。没有自动定时停服更新，避免比赛期间中断。

## 6. 启停与自动恢复

点击停止会先发送 quit，超时后终止本代理创建的进程组。点击重启会中断当前对局。页面关闭或只重启网页后端都不停止服务器；重启运行代理或整个 LXC 会停止游戏与 SteamCMD。

自动开服默认关，可在配置中启用；要求安装入口存在且无未完成维护。崩溃自动重试默认开，10 分钟最多 3 次，超过后停下让你排错。它不是无限循环守护。

## 7. 配置与局域网

sv_lan 固定 1。不提供任意 Shell、可执行文件路径或 RCON 输入。改端口须同步 PVE 防火墙，配置保存本身不改宿主规则。默认 map=dota，game_mode=1；0 表示不强制模式。模式编号、机器人和暂停命令是否适配当前版本要以游戏日志为准。

-insecure 和作弊开关默认关。-insecure 是关闭服务器 VAC 的选项，不是绕过 Steam 登录或免费许可的方法。不要为排查连接问题无差别开启所有选项。

跨 VLAN 时需要网络可达、明确的白名单以及游戏本身允许连接；Wi-Fi AP 隔离也可能阻止设备互通。面板能打开并不证明游戏 UDP 路径正常。

## 8. 配置备份和恢复

修改配置、维护前自动保存快照，也可手动备份；最多保留 20 份。恢复前须停服，会再备份当前配置。下载文件可能含游戏连接密码和 Steam 账号名；不含 Steam 密码、登录缓存、面板管理员密码或游戏资源。

配置恢复不回滚 Dota 2 版本，不恢复正在进行的比赛。需要全量恢复时使用 PVE 备份，且应保护其中的 Steam 登录缓存等敏感数据。

## 9. 常用恢复命令

```bash
# PVE：270 应换成自己的 CTID
pct enter 270

# 以下为 LXC 内部命令
dota-cli status
dota-cli jobs
dota-cli logs --name server
dota-cli stop
systemctl status dota-agent dota-panel nginx --no-pager
journalctl -u dota-agent -u dota-panel -n 150 --no-pager
```

## 10. 资源和支持边界

配置固定 6 vCPU / 6 GiB / 250 G，另有默认 1 GiB swap 额度；不能保证所有模式和人数在 6 GiB 内稳定运行。通过 cgroup/PVE 检查 OOM，而不是只凭平均占用判断。

初装空闲磁盘阈值 100 GiB、后续更新 20 GiB，是保护性下限，不是对未来 Steam 内容大小的保证。日志有限轮转，不会主动删除游戏下载目录来省空间。

需要接手排查时，导出“诊断 JSON”，自己检查无秘密再交给接手者。不要发送整个 Steam home 或完整 PVE 备份。完整的现场验收标准在 ACCEPTANCE.md。
