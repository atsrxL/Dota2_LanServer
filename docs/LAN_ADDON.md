# LAN 附加模式使用帮助 · 1.3.0

## 这版提供什么

完整 HTTP 免登录面板（沿用 SteamCMD/机器人版本库/CPU/每核/内存监控），加一个 `lan_dota` 附加模式。比赛由 LXC 进程承载；玩家连接后在 Dota 内的自制 Panorama 页面配置，不再读取官方大厅。

代码包需要本地 Workshop Tools 编译 UI，并在每台客户端安装同版资源；不是上传 ZIP 立即可玩的已编译地图。标准 `dota` 地图和默认英雄是本轮唯一目标。天地星兼容性由验证模块收集证据，尚无真实对局结论。

## 第一次使用：交给本地 Codex

先按根目录 CODEX_LAN_HANDOFF.md 合并真实仓库、编译/导入 UI、升级已有 LXC、安装客户端包。保持6 vCPU/6 GiB/250 G，HTTP无密码。缺少 compiled 时面板显示资源不足，启动被阻止；“停服部署模块”可先部署纯源码做检查，但不会绕过启动检查。

## 先测试连接和准备，不加 AI

停服进入 LAN 附加模式页。勾选启用、关闭天地星实验，保存，确认资源状态，点击启动。客户端控制台执行面板上的 connect 命令。连接失败需看原始引擎日志，网页不能替代 Steam/Source2 的连接握手。

首位完成有效 UI 握手的玩家成为配置者。每人选择天辉/夜魇以及一个空闲意向位置，然后准备。配置者可设置选人时间30–120秒、赛前时间10–60秒、是否允许暂停；更改设置、成员或队伍会清空准备，避免旧配置误开局。配置者可以转移权限；断线后等待30秒重新选举，也可在网页准备阶段发出受限的重新选举指令。

只有所有连接中玩家完成握手、选边和准备，配置者才能开始。准备阶段无自动开局倒计时。非法身份、旧配置版本、占用位置、越界值、重复开局均在服务端拒绝，不只是隐藏按钮。

## 再测试天地星

在机器人页输入1627071163下载并选择一个固定版本。在 addon 页扫描，然后停服开启“天地星原生 Bot 实验”。下一次开服锁定脚本版本，生成当前 session 的原生 Bot 探针。

进游戏选择实验模式，设置难度（0–3整数，实际效果需验证），选择是否开始时补齐空位，勾选实验确认并保存。需要自动填充时当前实现使用 GameRules:BotPopulate：必须事先在面板主配置明确开启训练作弊并重启，引擎报告 cheats=true才会开局。本版不会偷偷开启作弊，不能承诺不公平难度或每侧难度都按脚本实现。

人类玩家全部准备后开始；Bot填充在选人阶段一次性调用，15秒内核对数量。未足额或引擎提前开局会报告异常，尝试关闭思考/暂停；不要把该局当成可继续正常游玩的成功局。保留日志后面板停止即可。

“意向位置”目前是待适配输入，不等于天地星原生房间槽位。当前未提供双边不同脚本、自动位置映射、不同地形或完整官方模式复刻。

## 页面里的证据如何读

| 显示 | 能说明什么 |
|---|---|
| 编译资源文件已核对 | 文件、来源 UI hash、资源头/清单相符，不证明引擎能渲染 |
| 已部署模块 | 受管文件复制完成，不证明地图或附加模式已启动 |
| 游戏进程运行中 | 只有进程存活，连接仍需验收 |
| 新鲜 setup 心跳 | 当前进程中的 addon 服务端脚本报告正等待配置 |
| UI_HELLO | 引擎事件来源已识别，客户端 revision匹配 |
| BOT_ENTRY | 当前会话某个原生 Bot 入口执行 |
| BOT_API / BOT_CONTEXT | 候选全局 API 存在性 / GetBot 此时是否有句柄 |
| BOT_CALLBACK | 被注入的回调体确实开始执行，非完整行为正确 |
| 完整 AI / 槽位 / 对局 | 始终需要现场验收，不自动填写通过 |

心跳15秒过期后不再显示为新鲜玩家状态。旧日志 token不进入新会话统计。回调计数是同入口/回调的最大观测值，不是各机器人调用总和；日志不是防伪认证，第三方Lua可输出任意内容。探针有额外负担，性能对比需要随后关闭探针再重测。

## 下一局、停用与恢复

比赛结束先在面板停止/重启进程，重新回到准备阶段；首版不使用 map 内热重开，避免残留玩家/监听器/探针。每局的游戏内配置当前不持久化，重启恢复安全默认值；网页的 addon启用、启动策略、Bot实验开关持续保存。

下载新机器人版本不改变当前局。自动崩溃重试仍使用原局版本/配置；更改 addon源码会使自动重试失败，需显式重新启动。停止后取消启用 addon可以回到原普通服流程，不需要删除CT。

配置文件在 `/var/lib/dota2/lan-addon/`，游戏模块在 `/srv/dota2/game/dota_addons/lan_dota/`。源码与编译资源由安装脚本以root-owned部署，运行代理仅写游戏目录/状态。不要直接编辑受管文件；开发改源码、重新编译和部署，哈希冲突先保存用户改动。
